# ntm-sgm-wgs

Scripts for benchmarked MAC genome recovery and lineage analysis.

Reads: NCBI BioProject `PRJNA1444780`, SRA study `SRP687912`.

`scripts/run_recovery.sh` runs the two recovery routes and residual-mixture check. The remaining scripts build the updated cohort, public context, accessory-block analyses and figures. Run a script with `--help` for its inputs.

Software versions and accession tables are provided with the paper.
